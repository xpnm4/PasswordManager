# Password Manager

Менеджер паролей на C++ с графическим интерфейсом на Qt.

## Возможности

- Создание мастер-пароля
- Авторизация через мастер-пароль
- Добавление записей с логином и паролем
- Удаление сохранённых записей
- Генерация надёжных паролей
- Хранение данных в файле
- GUI-версия на Qt
- Консольная версия приложения

## Сборка проекта

Для сборки нужен CMake и компилятор C++.

```bash
cmake -B build
cmake --build build
```

## Запуск

### GUI-версия

```bash
build\password_manager_gui.exe
```

### Консольная версия

```bash
build\password_manager_cli.exe
```

## Безопасность

Приложение использует мастер-пароль для доступа к хранилищу.  
Данные сохраняются локально в файле `vault.dat`.

Важно: файл `vault.dat` не рекомендуется загружать в GitHub, так как он может содержать пользовательские данные.

## Что не нужно загружать в репозиторий

В `.gitignore` желательно добавить:

```gitignore
build/
vault.dat
*.exe
*.dll
*.log
.vscode/
```
